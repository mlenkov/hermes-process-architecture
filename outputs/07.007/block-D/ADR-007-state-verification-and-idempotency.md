# ADR-007: Проверка текущего состояния и идемпотентность (КРИТИЧЕСКИ ВАЖНО)

**Дата:** 2026-08-01
**Статус:** Утверждён
**Автор:** architect
**Профстандарт:** 07.007 «Специалист по процессному управлению»

---

## Проблема

Повторный запуск навыка в текущей архитектуре приводит к побочным эффектам:

- **Дублирование данных** — навык генерирует новый артефакт поверх существующего,
  не проверяя наличие.
- **Перезапись валидных артефактов** — повторный прогон затирает ранее принятый
  результат (`quality.schema_valid: true`), даже если данные не менялись.
- **Рассинхронизация `labor-coverage-registry.yaml`** — registry и фактическое
  состояние артефактов расходятся: запись обновляется независимо от того,
  перегенерирован ли артефакт.

Навык запускается многократно (перезапуск pipeline, crash recovery, selfheal) —
каждый запуск не должен иметь побочных эффектов при неизменном входе.

## Контекст

Сейчас исполняемый код навыка (секция `## Process`) сразу приступает к чтению
источников и генерации (Шаг 1), перезаписывая `output_files[0]`. Шаг проверки
текущего состояния отсутствует. Исполнение через `td_runner.py`
(и аналогичный механизм в `architect-executor`) вызывает `generate()` безусловно.

## Варианты

### А: Всегда перегенерировать (status quo)

**Плюсы:** нет изменений в навыках.
**Минусы:** перезапись валидных артефактов; рассинхронизация registry;
неидемпотентно; риск потери принятых результатов.

### Б: Версионирование артефактов (история прогонов)

**Плюсы:** история изменений сохраняется.
**Минусы:** рост файлов; сложность ссылок (registry/kanban указывают на «текущую»
версию); избыточно для текущего уровня зрелости.

### В: Pre-flight Check — идемпотентный Шаг 0 (ВЫБРАН)

**Плюсы:** нулевые побочные эффекты при повторе; простой и детерминированный
алгоритм; registry остаётся единственной точкой истины; совместимо с crash recovery.
**Минусы:** требует добавить Шаг 0 во все навыки (разовая миграция).

## Решение

**Выбран вариант В.** Каждый новый `SKILL.md` обязан начинать Python-код с
**Шага 0: Проверка текущего состояния (Pre-flight Check)** перед генерацией.

### Алгоритм Шага 0

```
1. Проверить, существует ли целевой файл output_files[0].
   └─ Нет  → продолжить на Шаг 1 (Генерация).
2. Если существует — прочитать и проверить quality.schema_valid == true.
   └─ Невалиден → продолжить на Шаг 1 (перегенерировать, восстановить артефакт).
3. Если файл существует и валиден — проверить labor-coverage-registry.yaml:
   запись этой ТФ имеет статус covered ИЛИ partially_covered
   И skill_path указывает на текущий навык.
   └─ Registry в порядке →
        лог: [INFO] Artifact already exists and is valid. Registry is up to date. Skipping generation.
        завершить работу успешно (exit 0), НЕ перезаписывая данные.
4. Если файл отсутствует / невалиден / registry рассинхронизирован —
   продолжить Шаги 1-5 (Генерация, Валидация, Запись).
```

### Правила

- **Идемпотентность:** навык можно запускать многократно без побочных эффектов.
- **Skipping — не ошибка:** завершение со `schema_valid: true` и exit-кодом 0,
  без записи в `output_files[0]`.
- **Рассинхронизация = перегенерация:** если артефакт валиден, но registry
  не содержит записи/статуса/skill_path — навык продолжает генерацию и
  синхронизирует registry.
- **Лог обязателен:** при skip выводится строка
  `[INFO] Artifact already exists and is valid. Registry is up to date. Skipping generation.`

### Скелет Шага 0 (обязательная преамбула)

```python
# ── Шаг 0: Pre-flight Check (идемпотентность, ADR-007) ────────────
if output_files:
    target = output_files[0]
    if os.path.exists(target):
        try:
            existing = yaml.safe_load(open(target, encoding="utf-8")) or {}
        except Exception:
            existing = {}
        if existing.get("quality", {}).get("schema_valid") is True:
            reg_entry = read_registry_entry(tf_code)          # из labor-coverage-registry.yaml
            reg_ok = reg_entry and reg_entry.get("status") in ("covered", "partially_covered")
            skill_ok = reg_entry and reg_entry.get("skill_path", "").endswith(current_skill_path)
            if reg_ok and skill_ok:
                print("[INFO] Artifact already exists and is valid. Registry is up to date. Skipping generation.")
                os._exit(0)                                    # успешный skip, без записи
```

## Последствия

- **Плюс:** повторные запуски безопасны; crash recovery не дублирует данные.
- **Плюс:** registry остаётся синхронизированным с артефактами.
- **Минус:** требуется миграция всех существующих навыков (добавить Шаг 0),
  включая td-gen и standalone-навыки.
- **Минус:** обновить `new-skill-architecture-blueprint.md` — Шаг 0 становится
  обязательной частью шаблона новых навыков.
