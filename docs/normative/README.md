# Нормативная база профессиональных стандартов РФ

Документы, определяющие структуру, порядок разработки и применения профессиональных стандартов в Российской Федерации.

## Состав

| № | Документ | Содержание |
|---|----------|-----------|
| 1 | **Приказ Минтруда № 147н** от 12.04.2013 | Макет профессионального стандарта — форма и структура документа |
| 2 | **Приказ Минтруда № 148н** от 12.04.2013 | Уровни квалификации (1–9) для подготовки профстандартов |
| 3 | **Приказ Минтруда № 170н** от 29.04.2013 | Методические рекомендации по разработке профстандарта |
| 4 | **Приказ Минтруда № 671н** от 30.09.2014 | Организация профессионально-общественного обсуждения |
| 5 | **Приказ Минтруда № 667н** от 29.09.2014 | Реестр профессиональных стандартов |
| — | **Постановление № 23** от 22.01.2013 | Правила разработки и утверждения профстандартов |
| — | **ТК РФ ст. 195.1–195.3** | Определение профстандарта, обязательность применения |

## Ключевое определение

> **Профессиональный стандарт** — характеристика квалификации, необходимой для осуществления определённого вида профессиональной деятельности, в том числе выполнения определённой трудовой функции.
> — ТК РФ, ст. 195.1

## Иерархия понятий

```
Профессиональный стандарт
  └── Обобщённая трудовая функция (ОТФ) — level N
        └── Трудовая функция (ТФ) — level N
              ├── Трудовые действия (ТД) — что делает
              ├── Необходимые умения — что умеет
              └── Необходимые знания — что знает
```

## Связь с архитектурой Hermes

Эти документы — нормативная основа для отображения профстандартов РФ в исполняемые навыки Hermes Agent. Граф знаний строится в строгом соответствии с макетом профстандарта (Приказ 147н) и методическими рекомендациями (Приказ 170н).
