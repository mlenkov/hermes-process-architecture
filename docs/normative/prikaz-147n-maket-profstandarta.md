# Приказ Минтруда № 147н — Макет профессионального стандарта

**Дата:** 12 апреля 2013 г.
**Полное название:** «Об утверждении макета профессионального стандарта»
**Статус:** Действует (с изменениями)

## Структура макета

Макет профстандарта определяет **обязательную форму** документа. Она состоит из четырёх разделов:

### I. Общие сведения

| Поле | Описание |
|------|----------|
| Вид деятельности | Наименование вида профессиональной деятельности |
| Цель | Основная цель вида профессиональной деятельности |
| ОКЗ | Коды Общероссийского классификатора занятий |
| ОКВЭД | Коды Общероссийского классификатора видов экономической деятельности |

### II. Описание трудовых функций (функциональная карта)

Таблица, где строки — ОТФ, столбцы — ТФ, ячейки — уровни квалификации.

| Код ОТФ | ОТФ | Уровень | ТФ (код) | ТФ (название) | Уровень |
|---------|-----|---------|----------|---------------|---------|

### III. Характеристика обобщенных трудовых функций

Для каждой ОТФ (по одной на подраздел):

**3.1. Метаданные ОТФ:**
- Код, наименование, уровень квалификации
- Возможные наименования должностей
- Требования к образованию и опыту
- Особые условия допуска
- Ссылки на ОКЗ, ЕКС, ОКПДТР, ОКСО

**3.2. Трудовая функция (ТФ):**
Для каждой ТФ в составе ОТФ:

```
Трудовые действия (перечень):
  1. Конкретное действие
  2. Конкретное действие
  ...

Необходимые умения (перечень):
  - Умение 1
  - Умение 2
  ...

Необходимые знания (перечень):
  - Знание 1
  - Знание 2
  ...
```

### IV. Сведения об организации-разработчике

- Ответственная организация
- Соисполнители
- Руководитель разработки

## Ключевые определения (из макета)

| Термин | Определение |
|--------|------------|
| **ОТФ** | Совокупность связанных ТФ, сложившихся в результате разделения труда |
| **ТФ** | Набор взаимосвязанных ТД, направленных на решение конкретной задачи |
| **ТД** | Конкретное действие работника в процессе выполнения ТФ |
| **Умения** | Навыки, необходимые для выполнения ТД |
| **Знания** | Теоретическая информация, необходимая для выполнения ТД |

## Выводы для архитектуры

1. **ТД — атомарные единицы** внутри ТФ, а не самостоятельные функции
2. **Умения и знания описываются на уровне ТФ**, а не отдельных ТД — все ТД одной ТФ требуют одного набора компетенций
3. **Порядок ТД в перечне соответствует последовательности** выполнения в рамках ТФ
4. ОТФ группирует ТФ по уровню квалификации исполнителя
