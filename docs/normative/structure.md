# Структура профстандарта: ОТФ → ТФ → ТД

Сводка по иерархии понятий и их отображению в граф знаний.

## Иерархия

```
Профессиональный стандарт (07.007)
  │
  └── Обобщенная трудовая функция (ОТФ) ─── уровень квалификации
        │                                     исполнитель (должность)
        │                                     требования к образованию/опыту
        │
        └── Трудовая функция (ТФ) ─────────── код (X/YY.Z)
              │                                наименование
              │                                уровень квалификации
              │
              ├── Трудовое действие (ТД) ────── что делает (глагольное сущ.)
              ├── Трудовое действие (ТД)
              ├── ...                          
              ├── Необходимые умения ────────── что умеет (глагол)
              └── Необходимые знания ────────── что знает (сущ.)
```

## Правила из нормативных документов

### Из макета (Приказ 147н)

> **ТД** — конкретное действие работника в процессе выполнения ТФ.
> Умения и знания описываются на уровне ТФ, не на уровне ТД.

### Из методических рекомендаций (Приказ 170н)

> ТД формулируются как **глагольные существительные** («Определение…», «Сбор…»).
> Перечень ТД должен быть **достаточным и необходимым** для функции.
> Порядок ТД в перечне соответствует последовательности выполнения.

## Подтверждение на данных 07.007 (120 ТД)

Проанализированы все 18 ТФ, 120 ТД. Выводы:

| Свойство | Подтверждение |
|----------|---------------|
| ТД — строго последовательны | 18/18 ТФ — линейный порядок, нет альтернатив |
| ТД — подшаги ТФ | Каждая ТФ — законченный процесс из 3–10 ТД |
| Умения/знания общие для ТФ | Все ТД одной ТФ наследуют одни умения и знания |
| Уровень квалификации | Все ТД одной ТФ имеют одинаковый уровень (6 или 7) |

## Спорные случаи

Некоторые ТФ содержат ТД, которые на первый взгляд выглядят как отдельные функции:

- **С/02.7** (Разработка системы управления): ТД включают «Разработку методологии» и «Подготовку презентаций» — разные по характеру, но в рамках одной ТФ это этапы одного процесса
- **D/04.7** (Методики трансформации): «Разработка методик» и «Контроль соблюдения методик» — фазы цикла (plan → do → check)

Во всех случаях ТД остаются последовательными этапами единой функции.

## Отображение в графе

```yaml
standard:
  id: standards_07_007
  type: standard
  children:
    - otf_a (generalized_labor_function, level 6)
      children:
        - tf_a01 (labor_function)
          skills: [skill_1, skill_2, ...]
          knowledge: [know_1, know_2, ...]
          tasks:
            - task_a01_1 (task, action_verb="Определение", sequence_index=1)
            - task_a01_2 (task, action_verb="Определение", sequence_index=2)
            - ...
          profile: specialist_reglamentatsii (profile, level 6)
    - otf_b ...
```

- **Стало:** ТФ → requires_skill → Skill (~90 edges), ТФ → requires_knowledge → Knowledge (~72 edges)
